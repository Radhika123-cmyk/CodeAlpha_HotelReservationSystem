# CodeAlpha Hotel Reservation System

## 📌 Project Overview

The **Hotel Reservation System** is a Java-based desktop application developed as part of the **CodeAlpha Internship**.

The application provides a graphical user interface (GUI) for searching hotel rooms, making reservations, managing bookings, cancelling reservations, and viewing booking details.

The system supports different room categories such as **Standard, Deluxe, and Suite**. It also includes simulated payment processing and uses **File I/O** to store reservation information.

---

## 🎯 Objectives

The main objectives of this project are:

- To develop a user-friendly hotel reservation system.
- To search for available rooms based on category and dates.
- To allow users to make hotel room reservations.
- To prevent double booking of rooms.
- To provide reservation cancellation functionality.
- To simulate the payment process.
- To display complete booking details.
- To store reservation data using File I/O.
- To demonstrate Object-Oriented Programming concepts in Java.

---

## ✨ Features

- 🏨 Room categorization
  - Standard
  - Deluxe
  - Suite

- 🔍 Search available rooms
- 📅 Check-in and check-out date management
- 📝 Make hotel reservations
- 🚫 Prevent overlapping room bookings
- 💳 Simulated payment processing
- 🆔 Automatic reservation ID generation
- 💰 Automatic calculation of total booking amount
- ❌ Cancel reservations
- 📋 View reservation details
- 💾 Store bookings using File I/O
- 🔄 Load previous bookings when the application starts
- 🖥️ Java Swing graphical user interface
- ✅ Input validation
